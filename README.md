# Project Idea: 
Green Guardian is a smart greenhouse system that uses IoT sensors and edge computing to detect risky conditions, sends an autonomous drone to inspect plants, uses AI to analyze possible pests or diseases, and displays the results, alerts, and recommendations on one farmer dashboard.
